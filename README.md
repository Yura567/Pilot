# PILOT — Crash Game

Демо-гра в стилі Aviator/Crash з літаком та множником.

## Запуск

```bash
npm install
npm run dev
```

Відкрийте http://localhost:5173 у браузері.

## Як грати

1. Введіть суму ставки (мін. 10 ₴)
2. Натисніть **ЗРОБИТИ СТАВКУ** під час очікування
3. Літак злетить — множник зростає
4. Натисніть **ЗАБРАТИ ВИГРАШ** до краху
5. Якщо літак розіб'ється раніше — ставка програна

## Функції

- Сцена на PixiJS: гвинтовий літак, промені, крива з заливкою, «FLEW AWAY»
- Авто-кешаут
- Історія раундів
- Стрічка гравців (симуляція)
- Віртуальний баланс 1000 ₴

> Це демо з віртуальними коштами. Без реальних грошей.
